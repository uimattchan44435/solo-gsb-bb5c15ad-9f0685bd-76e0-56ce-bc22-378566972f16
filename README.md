# 树轮交叉定年工作台（Tree-Ring Cross-Dating Workbench）

用 **React + TypeScript + Node.js（Express）** 实现的树轮宽度序列交叉定年工具。
录入**已标年份的参考序列**与**待定年样本序列**（宽度均为正整数），以参考序列中的
每个连续年份作为候选起点，用动态规划求最优对齐，支持样本**漏记（缺轮）最多 2
个真实年份**或出现**最多 2 个不计年伪轮**，并导出 CSV。

## 一条命令启动

```bash
docker compose up --build
```

启动后浏览器访问：

**http://localhost:8080**

- 容器内服务监听 `3000` 端口，宿主机映射为 `8080`（见 `docker-compose.yml`）。
- 容器**启动时自动执行 `npm install` 安装依赖**、`npm run build` 构建前端，然后启动服务（见 `docker-entrypoint.sh`）。

停止：`docker compose down`。

## 本地开发（不用 Docker）

```bash
npm install
npm run dev          # 前端 Vite，http://localhost:5173（/api 代理到 3000）
npm run dev:server   # 另开一个终端：Express + tsx 热重载，http://localhost:3000
```

生产模式（单端口托管前端 + API）：

```bash
npm run build
npm start            # http://localhost:3000
```

## 数据录入格式

参考序列（每行 `年份,宽度`，支持逗号/空格/Tab/分号分隔，`#` 开头为注释）：

```
1990,42
1991,58
1992,35
```

- 年份必须是连续整数（排序后逐年 +1，不允许断年或重复），宽度为正整数。

样本序列（每行一个正整数宽度，也支持 `序号,宽度`）：

```
86
33
64
```

点击 **「载入示例数据」** 可快速体验：样本真实对应 1995–2008 年，含 1 个缺轮
（2003 年）与 1 个伪轮，最优结果总代价 200。

## 算法说明

### 操作与代价

| 操作 | 含义 | 样本轮游标 | 参考年份游标 | 代价 |
|------|------|:---:|:---:|------|
| `M` | 正常配对 | 前进 | 前进 | `|样本宽度 − 参考宽度|` |
| `L` | 漏记（缺轮） | 不动 | 前进 1 个真实年份 | `100` |
| `F` | 伪轮（不计年） | 前进 | 不动 | `100` |

- 漏记年份数 `L ≤ 2`、伪轮数 `F ≤ 2`。
- **首尾操作强制为 `M`**：首部缺轮等价于换一个更晚的候选起点且少付 100
  分，尾部缺轮不消费任何样本轮，二者都不可能出现在最优解中；这也是树轮学
  交叉定年的常规假设（样本最内、最外层轮均真实）。

### 动态规划

- 对参考序列中每一个能容纳样本的位置作为**候选起始年份**（参考长度为 m、
  样本为 n，共评估 O(m) 个起点）。
- 状态压缩为 `(j, a, b)`：已消费样本轮数 j、累计缺轮 a、累计伪轮 b；
  已消费参考偏移 `k = j + a − b`，因此无需显式存储 k。
- 转移：
  - `F → (j+1, a, b+1)`，代价 100；
  - `L → (j, a+1, b)`，代价 100；
  - `M → (j+1, a, b)`，代价 `|s[j] − r[start+k]|`。
- 每个起点先用前向 DP 求最小总代价，再用反向启发值 DP 做贪心重建，
  保证在同代价路径中得到**字典序最小**的操作序列（字典序 `F < L < M`）。
- 单起点复杂度 O(n·3·3) = O(n)，整体 O(m·n)。

### 平局裁决

1. 总代价最低；
2. 总代价相同取**起始年份最早**；
3. 仍相同取**操作序列字典序最小**（ASCII 顺序即 `F < L < M`）。

### 结果展示

- 概览卡片：最优起始/结束年份、最低总代价（配对差和 + 罚分明细）、
  配对/缺轮/伪轮计数、**缺轮年份单独列出**。
- 候选起点前 10 名表格（可点击查看任意候选的对齐明细）。
- 逐行明细：**年份、样本位置（1 基）、样本宽度、参考宽度、操作、本行代价、
  累计代价**；缺轮行高亮并标注「缺轮年份」，伪轮行标注「不计年」并沿用其
  前一配对年份。
- **导出结果 CSV**：含摘要行（起始年、总代价、操作序列、缺轮年份等）与
  逐行明细，带 UTF-8 BOM，Excel 直接打开不乱码。

## 接口

- `GET /api/health` 健康检查。
- `POST /api/crossdate`

  ```json
  {
    "referenceText": "1990,42\n1991,58",
    "sampleText": "42\n58"
  }
  ```

  返回最优对齐、全部候选及逐行明细；输入不合法返回 400 与中文错误信息。
